Entry for the make.fun bounty [The 3 AM Excuse](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878): a program that writes a single line of under 200 characters to `/output/entry.txt` — the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM.

The line (v1):

> All 24 of my words held a vote at 3 AM. It was 24–0 against you.

Run it with `python3 main.py`. It writes exactly 64 characters, no trailing newline.
